# Reel Publish Checklist

## Export

- Resolution is 1080x1920 (9:16)
- Duration is between 3 and 90 seconds
- Video codec is H.264 and audio codec is AAC
- File extension is .mp4
- Captions are readable in mobile safe zones

## Content Quality

- Hook appears in first 1 to 3 seconds
- CTA is present near the end
- Audio levels are balanced and clear
- No clipped text or cropped overlays

## Delivery

- Thumbnail/cover frame is selected
- Caption draft and hashtags are prepared
- Final file is named consistently for publishing workflow
